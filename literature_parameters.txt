PAPER 2
  Authors : Mulkers, Milošević, Van Waeyenberge
  Title   : Cycloidal versus skyrmionic states in mesoscopic chiral magnets
  Journal : Physical Review B 93, 214405 (2016)
  DOI     : 10.1103/PhysRevB.93.214405
--------------------------------------------------------------------------------

  Material      : Pt/Co thin film (interfacial Cnv DMI)
  Geometry      : thin strips and square platelets (2D, PMA)
  Thickness     : t = 0.4 nm (single atomic layer approximation)
  Cell size     : 1 nm × 1 nm × 0.4 nm

  Material parameters (Pt/Co):
    Msat          : 580 kA/m  = 580e3 A/m
    A (exchange)  : 15 pJ/m   = 15e-12 J/m
    K (anisotropy): 0.8 MJ/m³ = 0.8e6 J/m³
    Keff          : K - (1/2)*mu0*Msat² ≈ 0.59 MJ/m³
    D (DMI)       : 3–5 mJ/m² (scanned in paper)
    Dc (critical) : 4*sqrt(A*Keff) ≈ 4.0 mJ/m²  [boundary uniform↔cycloid]
    B_ext         : 0 T (ground state study)

  Geometry ranges studied:
    Strips  : width w = 20–200 nm, infinite length (periodic BC along y)
    Platelets: side length l = 20–200 nm (square)

  Key results:
    - For D < Dc: ground state is quasi-uniform (ferromagnetic)
    - For D > Dc: ground state is cycloidal; larger w → more domain walls
    - Skyrmions appear as excited states or near D ≈ Dc in circular geometry

            Nagaosa, Tokura
  Title   : Geometrically stabilized skyrmionic vortex in FeGe tetrahedral
            nanoparticles
  Journal : Nature Materials 21, 305–310 (2022)
  DOI     : 10.1038/s41563-021-01186-x
--------------------------------------------------------------------------------

  Material      : B20-type FeGe (bulk cubic helimagnet, T-symmetry DMI)
  TC            : ~280 K
  Observation   : 10 K (electron holography) and RT (above TC for structure)

  Geometry (nanoparticles):
    Shape         : tetrahedra with (111) facets
    Size range    : 100–600 nm (edge length)
    Key sizes     : 110 nm, 145 nm, 185 nm, 255 nm, 300 nm
    Cell size used in simulations: 3 nm × 3 nm × 3 nm

  Material parameters used in MuMax3 simulations:
    Ms            : 384 kA/m  = 384e3 A/m
    A (exchange)  : 4.75 pJ/m = 4.75e-12 J/m
    D (DMI, bulk) : 0.8527 mJ/m² = 0.8527e-3 J/m²  [bulk T-type, Dbulk]
    Kc1 (cubic)   : -6 kJ/m³  = -6e3 J/m³
    Kc2 (cubic)   : +12 kJ/m³ = +12e3 J/m³
    Surface Ks    : 95 J/m²  (easy-plane, for 145 nm particle only)
    B_ext         : 0 T (zero-field ground state study)
    Helical wavelength: ~70 nm (bulk FeGe literature value)

  Phase diagram (from simulations + EH experiment):
    < 130 nm      : single skyrmionic vortex (ground state, robust up to TC)
    ~130–200 nm   : 1–3 skyrmionic vortices
    ~200–300 nm   : helical state with q along [100]
    > 300 nm      : helical state with q along [111]
